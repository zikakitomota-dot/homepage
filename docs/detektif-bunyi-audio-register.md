## Processing and attribution

Short excerpts were converted to mono 22050 Hz PCM WAV, with peak amplitude limited to -9 dBFS and short edge fades. The single clock tick was repeated with silence. These formats prioritise native decoding; files are 88-243 kB each and only load on playback. Total audio size is 1837744 bytes. There is no preload of the entire library.

## Owner listening checklist

For each clip, play it on desktop and a phone at a comfortable volume. Confirm the intended source, recognisability, no answer-revealing speech, tolerable start/end, no confusing background noise, and safe volume. Review rain/water/wind/waves side by side before approving Intermediate and Challenge distractors. Check the two-sound order tasks too. Record reviewer, date, result and any replacement needed. Do not change verification status merely because the file loads.
