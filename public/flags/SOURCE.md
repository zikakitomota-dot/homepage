# Flag asset source

The 54 SVG files in this directory are a curated subset of the
[`hampusborgos/country-flags`](https://github.com/hampusborgos/country-flags)
repository. Files use lowercase ISO 3166-1 alpha-2 country codes.

The source repository states that its accurate flag renders are based primarily
on Wikimedia Commons and that national flags are public-domain works, while
noting that local restrictions may apply to how flags are used. Assets were
retrieved on 19 October 2026 and are stored locally so the game has no runtime
dependency on a third-party flag service.
